# libs/CCFbo/AGENTS.md

Tiny FBO helper. One header + one implementation, used by `qCC_db` and `qCC_glWindow` for offscreen rendering (picking buffer, GL filter passes).

**CMake target:** `CC_FBO_LIB` (SHARED).

There is nothing to edit here unless you're doing OpenGL plumbing.
