# rust_cxx_app template

Rust + CXX FFI. The Rust crate compiles to a static library; a small C++
implementation provides a function callable from Rust.

## Quick start

```powershell
cargo build
cargo test
cargo run --bin demo_cli -- 1 2 3 4 5
```

You should see:

```
[C++ says] Hello, Rust, from C++!
[Rust says] sum = 15, mean = 3.000000
```

## What you get

- `src/lib.rs` — the `#[cxx::bridge]` module + `mean_rust` / `sum_rust` (callable from C++)
- `src/main.rs` — CLI that calls C++ (`greet_from_cpp`) and Rust
- `cpp/bridge.cc` — the C++ implementation of `greet_from_cpp`
- `build.rs` — wires cxx-build to compile `cpp/bridge.cc`

## Generated files (do NOT commit)

- `target/` — cargo build output
- `cpp/bridge.h` — auto-generated by cxx-build from the `#[cxx::bridge]` module
- `Cargo.lock` — pinned dependency versions (the repo `.gitignore` excludes this for templates)

## How to extend

See `AGENTS.md` for the full recipe. Quick:

| Want to... | Edit |
|---|---|
| Add a C++ function callable from Rust | `src/lib.rs` `extern "C++"` block + `cpp/bridge.cc` |
| Add a Rust function callable from C++ | `src/lib.rs` `extern "Rust"` block + `pub fn` impl |
| Add a shared struct | `struct Foo { ... }` in the bridge module |

## What this template does NOT do

- No Qt GUI (use `../cpp_qt_gui/` and link this crate)
- No Sentry wired (add the `sentry` feature yourself if needed)
- No async (CXX FFI is sync only)
